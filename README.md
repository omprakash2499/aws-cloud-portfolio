## Projects

### [Public and private subnets with EC2](01-secure-vpc-ec2/README.md)

I deployed a VPC with a public test instance and a private Nginx server using CloudFormation. I checked that the test instance could reach the web server and that the private instance could reach the internet without a public IP. I then deleted the stack.

**Used:** VPC, EC2, NAT Gateway, IAM, Systems Manager, CloudFormation, Bash and Nginx.
