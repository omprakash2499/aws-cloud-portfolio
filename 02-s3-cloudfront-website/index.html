AWS Cloud Portfolio / Project 02

Private origin.
Public website.

A static website delivered through Amazon CloudFront, with its files stored in a private Amazon S3 bucket.

Store privately

S3 stores the website files with Block Public Access enabled.

Deliver over HTTPS

CloudFront provides the public URL and redirects HTTP requests to HTTPS.

Control origin access

Origin Access Control signs requests. The bucket policy grants this distribution read access.

Built with S3, CloudFront, CloudFormation and Bash. private-origin-lab-v1
